# ROVQIX

The ROVQIX marketing site and its area subdomains: **1.5 million fully static pages**, with no backend, server or Workers, deployed to Cloudflare Pages at no cost.

A Turborepo monorepo (npm workspaces). Next.js 16, TypeScript, Tailwind 4, Framer Motion.

```
apps/
  web/                         rovqix.in: the main site
  plumber-websites/            plumber-websites.rovqix.in
  dental-practice-websites/    dental-practice-websites.rovqix.in
  … 99 trade sites in total (apps/*-websites), generated by scripts/create-area-apps.mjs
packages/
  shared/               @rovqix/shared: design system, navbar/footer, landing pages + layout, SEO
  area-site/            @rovqix/area-site: the pages, layout and build steps every trade site shares
  areas/                @rovqix/areas: page generator, 14 page variants, 1,107 cities, site registry
    types/<type>.ts     one file per business type
  typescript-config/    shared tsconfig
scripts/
  create-area-apps.mjs    (re)generates the 100 apps/*-websites folders
  check-export-size.mjs   fails a build that would exceed Cloudflare's 20,000-file limit
  cloudflare-projects.mjs prints the Cloudflare Pages settings for every site
  cloudflare-setup.mjs    creates the 100 Cloudflare projects, domains and DNS (run by the deploy workflow)
  affected-sites.mjs      decides which sites a push needs to redeploy
.github/workflows/deploy.yml  builds on GitHub and uploads to Cloudflare Pages
```

## The 99 trade sites

Each business type gets its own site with a keyword subdomain (`plumber-websites.rovqix.in`, `wedding-venue-websites.rovqix.in`, …). Each site covers 14 page variants (web design, website cost, SEO, redesign, booking, landing page, maintenance, Google Business Profile, hosting, web developer, mobile, speed, copywriting, agency) × 1,107 cities = **15,498 pages**, about 15,550 files. Cloudflare allows 20,000.

99 sites × 15,498 = **1,534,302 pages**. `rovqix.in/areas` links to every site and `rovqix.in/sitemap.xml` indexes every URL (63 chunks). Each site also has its own `sitemap.xml`. Old `rovqix.in/areas/...` URLs 301 to their trade site.

## Local development

```bash
npm install
npm run dev                                        # rovqix.in on http://localhost:3000
npm run dev:area                                   # plumber-websites on http://localhost:3000
npx turbo run build --filter=@rovqix/web           # -> apps/web/out
npx turbo run build --filter=@rovqix/plumber-websites   # -> apps/plumber-websites/out
npm run validate -w @rovqix/areas                  # build + check all 1.55M pages in memory (~15 s)
npm run lint && npm run typecheck
```

Requires Node 22 (see `.node-version`).

## Deploying with GitHub Actions

GitHub builds every site and uploads it to Cloudflare Pages (`.github/workflows/deploy.yml`). Nothing is built on your machine or by Cloudflare. Cloudflare has 100 projects: `rovqix` (rovqix.in) plus `rovqix-<trade>-websites` for the 99 trade sites, all Direct Upload.

### One-time setup

1. **Cloudflare API token:** dash.cloudflare.com → My Profile → API Tokens → Create Token → *Create Custom Token*, with these permissions:
   - Account › **Cloudflare Pages** › Edit
   - Zone › **DNS** › Edit, and Zone › **Zone** › Read. Under *Zone Resources*, choose Include › Specific zone › rovqix.in.
2. **Account ID:** in the Cloudflare dashboard, click rovqix.in; it's on the right under *API → Account ID*.
3. **GitHub secrets:** in the repo, go to Settings → Secrets and variables → Actions → New repository secret:
   - `CLOUDFLARE_API_TOKEN` = the token
   - `CLOUDFLARE_ACCOUNT_ID` = the account ID
4. **Deploy everything:** go to the Actions tab → **Deploy** → *Run workflow* (leave "Projects" empty). The first run creates all 100 Cloudflare projects, their domains and DNS records, then builds and uploads every site, 20 at a time, in about 1–1.5 hours.

### After that

- **Every push to `main` deploys only the sites whose files changed.** A blog post deploys rovqix.in only. `packages/areas/types/plumber.ts` deploys plumber-websites plus rovqix.in. `packages/shared/` or `packages/area-site/` deploys all 100.
- **To redeploy specific sites:** Actions → Deploy → Run workflow with e.g. `rovqix,rovqix-plumber-websites`. `npm run cf:projects` lists every project name.
- **To preview locally which sites a commit range would deploy:** `node scripts/affected-sites.mjs <old-sha> <new-sha>`.

### Limits

- **GitHub Actions minutes:** a full deploy uses about 1,200–1,400 minutes. Public repos have no minute limit on standard runners. Private repos on GitHub Free get 2,000 minutes a month, so about one full deploy plus smaller ones. Up to 20 jobs run at once.
- **Cloudflare:** 100 projects per account, all used. Each site has at most 20,000 files; the largest trade site has about 15,550. Direct Upload doesn't count against Cloudflare's 500 builds a month.
- **Disk:** a trade site needs about 15 GB while building. The workflow deletes unused preinstalled tools from the runner first to make room.

## Search Console

Verify `rovqix.in` as a **Domain property** (DNS verification). That covers every subdomain and lets `rovqix.in/sitemap.xml` list subdomain URLs. Then submit `https://rovqix.in/sitemap.xml`.

## Forms

There is no backend. The contact, careers and newsletter forms open the visitor's email app or WhatsApp with the message pre-filled (`packages/shared/lib/compose.ts`).
